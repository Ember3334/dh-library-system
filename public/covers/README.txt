图书封面目录（public/covers/）
================================

【用途】
系统会按「索书号（call_no）」自动加载每本书的封面：
  封面文件命名 = 索书号 + .jpg
  例如索书号 I1-01 的封面应命名为：  I1-01.jpg
  浏览器访问地址为：  /covers/I1-01.jpg

当某本书没有对应封面文件时，系统会自动回退为「书名首字 + 渐变底色」占位图，
不影响任何功能，因此可先空着、后续再补图。

【命名规则】
1. 文件名必须与该书的「索书号」完全一致（区分大小写）。
2. 仅支持常见图片格式，推荐 .jpg（也支持 .png，但文件需命名为 <索书号>.png 并改对应逻辑）。
3. 索书号在本馆数据中仅含字母、数字、点、短横（如 I1-01 / K12.3），
   请勿使用中文或空格作为文件名，避免系统无法匹配。

【如何添加封面】
方式一（最简单）：
  把图片重命名为「索书号.jpg」，复制进本目录（public/covers/）即可，刷新页面即生效。

方式二（批量）：
  将一批图片按上述规则命名后整体放入本目录；系统检索图书时会自动逐本匹配。

【示例】
  索书号          封面文件
  ---------------  ----------
  I1-01           I1-01.jpg
  J2-15           J2-15.jpg
  K12.3           K12.3.jpg
  Z0-05           Z0-05.jpg

【注意】
- 封面不为必填项，缺图时显示优雅占位，无需为每本书都准备图。
- 后续按编码（索书号）新增书目时，只需保证 call_no 唯一，并放入对应封面即可。
- 建议封面尺寸统一为 300×420 左右（竖向 5:7），视觉效果最佳。
