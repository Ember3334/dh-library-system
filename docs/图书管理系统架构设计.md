# 图书管理系统架构设计（SpringBoot + 原生 HTML + 云 MySQL）

> 本文档为「数字人文学院图书管理系统」重构架构蓝图。
> 技术栈：**前端原生 HTML/CSS/JS（无框架）** + **后端 SpringBoot 3.x + MyBatis-Plus** + **MySQL 8.0（云端实例）**。
> 定位：前后端分离、带管理员权限；前端不保存任何业务数据，全部通过 `fetch` 调后端接口。
> 参考真实项目：meitanzai/book-manage-vue、xuzhili835/lms-system、JoeNJH/Library-Management-System。

---

## 1. 架构总览

### 1.1 分层架构

```
┌─────────────────────────┐      fetch (JSON)      ┌──────────────────────────────┐
│  前端（原生 HTML/JS）     │ ───────────────────▶ │  后端（SpringBoot + MP）       │
│  user/  普通用户页面      │ ◀─────────────────── │  Controller → Service → Mapper │
│  admin/ 管理员后台页面    │   统一响应体           │       ↓                      │
└─────────────────────────┘                        │  云 MySQL 8.0 实例            │
                                                  └──────────────────────────────┘
```

- **展示层**：`frontend/user/`（普通用户）、`frontend/admin/`（管理员后台）。纯静态文件，可放对象存储 / Nginx / CDN。
- **接口层**：`*.controller` 包，REST API，路径前缀 `/api`。
- **业务层**：`*.service` 包，封装借书/还书/评论/权限等逻辑，事务控制。
- **持久层**：MyBatis-Plus `BaseMapper`，零 XML 即可 CRUD；云 MySQL 单库。

### 1.2 角色与权限模型

- 单表 `user`，用 `role` 字段区分：`0=普通用户`，`1=管理员`。
- 普通用户 token 可访问：`/api/user/**`、`/api/books/**`、`/api/borrow/**`、`/api/comments/**`。
- 管理员 token 额外可访问：`/api/admin/**`。
- 鉴权方式：**JWT（无状态）**。登录成功后后端返回 token，前端存 `localStorage`，每次请求 `Authorization: Bearer <token>`。
- 拦截器校验：白名单（注册/登录）放行；其余校验 token 合法性；`/api/admin/**` 额外校验 `role==1`。

### 1.3 为什么数据必须上云

2000 名用户通过互联网访问，数据库必须部署在**云端 MySQL 实例**（腾讯云/阿里云学生机，几十元/年）。本机 MySQL 仅可用于本地调试，外网用户无法访问你的电脑，且关机/断网即全站不可用。详见第 6 章。

## 2. 数据库设计（建表 SQL）

字符集 `utf8mb4`，引擎 `InnoDB`。外键未强制（高并发下用逻辑外键 + 业务层保证），索引覆盖高频查询字段。

```sql
-- ========== 1. 用户表（普通用户 + 管理员共用，role 区分） ==========
CREATE TABLE `user` (
  `id`         BIGINT       NOT NULL AUTO_INCREMENT,
  `username`   VARCHAR(50)  NOT NULL,
  `password`   VARCHAR(100) NOT NULL                COMMENT 'BCrypt 加密密文',
  `role`       TINYINT      NOT NULL DEFAULT 0      COMMENT '0=普通用户,1=管理员',
  `real_name`  VARCHAR(50)  DEFAULT NULL,
  `phone`      VARCHAR(20)  DEFAULT NULL,
  `email`      VARCHAR(100) DEFAULT NULL,
  `status`     TINYINT      NOT NULL DEFAULT 1      COMMENT '1=正常,0=禁用',
  `created_at` DATETIME     DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME     DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_username` (`username`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';

-- ========== 2. 图书表 ==========
CREATE TABLE `book` (
  `id`         BIGINT       NOT NULL AUTO_INCREMENT,
  `title`      VARCHAR(200) NOT NULL,
  `author`     VARCHAR(100) DEFAULT NULL,
  `isbn`       VARCHAR(30)  DEFAULT NULL,
  `publisher`  VARCHAR(100) DEFAULT NULL,
  `category`   VARCHAR(50)  DEFAULT NULL,
  `call_no`    VARCHAR(50)  DEFAULT NULL            COMMENT '索书号/馆藏位置',
  `total`      INT          NOT NULL DEFAULT 1      COMMENT '馆藏总数',
  `available`  INT          NOT NULL DEFAULT 1      COMMENT '可借数量',
  `price`      DECIMAL(10,2) DEFAULT NULL,
  `intro`      TEXT,
  `cover`      VARCHAR(255) DEFAULT NULL            COMMENT '封面URL（可选）',
  `created_at` DATETIME     DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME     DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  KEY `idx_title` (`title`),
  KEY `idx_category` (`category`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='图书表';

-- ========== 3. 借阅记录表（核心业务表） ==========
CREATE TABLE `borrow` (
  `id`          BIGINT    NOT NULL AUTO_INCREMENT,
  `user_id`     BIGINT    NOT NULL,
  `book_id`     BIGINT    NOT NULL,
  `borrow_date` DATETIME  NOT NULL                COMMENT '借出时间',
  `due_date`    DATETIME  NOT NULL                COMMENT '应还时间（借出+30天）',
  `return_date` DATETIME  DEFAULT NULL            COMMENT '实际归还时间（NULL=未还）',
  `status`      TINYINT   NOT NULL DEFAULT 0      COMMENT '0=借阅中,1=已归还,2=逾期',
  PRIMARY KEY (`id`),
  KEY `idx_user` (`user_id`),
  KEY `idx_book` (`book_id`),
  KEY `idx_status` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='借阅记录表';

-- ========== 4. 评论表 ==========
CREATE TABLE `comment` (
  `id`         BIGINT    NOT NULL AUTO_INCREMENT,
  `user_id`    BIGINT    NOT NULL,
  `book_id`    BIGINT    NOT NULL,
  `content`    VARCHAR(500) NOT NULL,
  `rating`     TINYINT   DEFAULT NULL             COMMENT '评分 1-5（可选）',
  `status`     TINYINT   NOT NULL DEFAULT 1       COMMENT '1=正常,0=已屏蔽',
  `created_at` DATETIME  DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  KEY `idx_book` (`book_id`),
  KEY `idx_user` (`user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='图书评论表';
```

### 4.3 Service：借阅业务（事务核心）

```java
@Service
public class BorrowService {
    @Autowired private BorrowMapper borrowMapper;
    @Autowired private BookMapper bookMapper;

    /** 借书：扣减库存 + 写入借阅记录，事务保证原子性 */
    @Transactional(rollbackFor = Exception.class)
    public Borrow borrow(Long userId, Long bookId) {
        Book book = bookMapper.selectById(bookId);
        if (book == null) throw new RuntimeException("图书不存在");
        if (book.getAvailable() <= 0) throw new RuntimeException("库存不足，暂不可借");

        // 扣减可借数量
        book.setAvailable(book.getAvailable() - 1);
        bookMapper.updateById(book);

        // 写入借阅记录（应还 = 借出 + 30 天）
        Borrow borrow = new Borrow();
        borrow.setUserId(userId);
        borrow.setBookId(bookId);
        borrow.setBorrowDate(LocalDateTime.now());
        borrow.setDueDate(LocalDateTime.now().plusDays(30));
        borrow.setStatus(0); // 借阅中
        borrowMapper.insert(borrow);
        return borrow;
    }

    /** 还书：回填归还时间 + 恢复库存 + 逾期判定 */
    @Transactional(rollbackFor = Exception.class)
    public Borrow returnBook(Long borrowId) {
        Borrow borrow = borrowMapper.selectById(borrowId);
        if (borrow == null || borrow.getStatus() == 1) throw new RuntimeException("记录不存在或已归还");

        borrow.setReturnDate(LocalDateTime.now());
        // 逾期判定：实际归还晚于应还时间 → 标记逾期
        if (borrow.getReturnDate().isAfter(borrow.getDueDate())) {
            borrow.setStatus(2); // 逾期
        } else {
            borrow.setStatus(1); // 已归还
        }
        borrowMapper.updateById(borrow);

        // 恢复库存
        Book book = bookMapper.selectById(borrow.getBookId());
        book.setAvailable(book.getAvailable() + 1);
        bookMapper.updateById(book);
        return borrow;
    }
}
```

### 4.4 Service：评论

```java
@Service
public class CommentService {
    @Autowired private CommentMapper commentMapper;

    public Comment add(Long userId, Long bookId, String content, Integer rating) {
        Comment c = new Comment();
        c.setUserId(userId);
        c.setBookId(bookId);
        c.setContent(content);
        c.setRating(rating);
        c.setStatus(1); // 正常
        commentMapper.insert(c);
        return c;

    public void block(Long id) {
        Comment c = commentMapper.selectById(id);
        if (c != null) {
            c.setStatus(0);
            commentMapper.updateById(c);
        }
    }
}
```

```java
@RestController
@RequestMapping("/api")
@CrossOrigin // 或全局 CORS 配置（见 4.7）
public class ApiController {
    @Autowired private UserService userService;
    @Autowired private BorrowService borrowService;
    @Autowired private CommentService commentService;

        String token = jwtUtil.generate(u.getId(), u.getRole());
        return R.ok(Map.of("token", token, "user", u));
    }

    // 借书（从 JWT 取 userId）
    @PostMapping("/borrow")
    public R<Borrow> borrow(@RequestAttribute("uid") Long uid, @RequestBody Map<String,Long> body) {
        return R.ok(borrowService.borrow(uid, body.get("bookId")));
    }

    // 还书
    @PostMapping("/borrow/{id}/return")
    public R<Borrow> returnBook(@RequestAttribute("uid") Long uid, @PathVariable Long id) {
        return R.ok(borrowService.returnBook(id));
    }

    // 我的借阅
    @GetMapping("/borrow/my")
    public R<IPage<Borrow>> myBorrows(@RequestAttribute("uid") Long uid,
                                      @RequestParam(defaultValue="1") int page,
                                      @RequestParam(defaultValue="10") int size) {
        return R.ok(borrowService.pageByUser(uid, page, size));
    }

    // 发表评论
    @PostMapping("/comments")
    public R<Comment> addComment(@RequestAttribute("uid") Long uid, @RequestBody Comment c) {

    }
```

### 4.6 JWT 工具类 + 拦截器

```java
// JwtUtil.java
@Component
public class JwtUtil {
    private final String SECRET = "your-256-bit-secret-change-me"; // 生产用环境变量注入
    private final long EXPIRE = 1000L * 60 * 60 * 24; // 24h

    public String generate(Long uid, Integer role) {
        return Jwts.builder()
            .claim("uid", uid).claim("role", role)
            .setExpiration(new Date(System.currentTimeMillis() + EXPIRE))
            .signWith(SignatureAlgorithm.HS256, SECRET).compact();
    }
    public Claims parse(String token) {
        return Jwts.parser().setSigningKey(SECRET).parseClaimsJws(token).getBody();
    }
}

// AuthInterceptor.java —— 校验 token，写入请求属性供 Controller 使用
@Component
public class AuthInterceptor implements HandlerInterceptor {
    @Autowired private JwtUtil jwtUtil;
    @Override
    public boolean preHandle(HttpServletRequest req, HttpServletResponse resp, Object h) {
        String uri = req.getRequestURI();
        if (uri.contains("/user/login") || uri.contains("/user/register")
            || uri.contains("/admin/login") || uri.startsWith("/api/books")) {
            return true; // 白名单
        }
        String auth = req.getHeader("Authorization");
        if (auth == null || !auth.startsWith("Bearer ")) { resp.setStatus(401); return false; }
        try {
            Claims c = jwtUtil.parse(auth.substring(7));
            req.setAttribute("uid", c.get("uid", Long.class));
            req.setAttribute("role", c.get("role", Integer.class));
            // 管理员接口额外校验
            if (uri.startsWith("/api/admin/") && c.get("role", Integer.class) != 1) {
                resp.setStatus(403); return false;
            }
            return true;
        } catch (Exception e) { resp.setStatus(401); return false; }
    }
}

// WebConfig.java —— 注册拦截器 + 全局 CORS
@Configuration
public class WebConfig implements WebMvcConfigurer {
    @Autowired private AuthInterceptor authInterceptor;
    @Override public void addInterceptors(Registry registry) {
        registry.addInterceptor(authInterceptor).addPathPatterns("/api/**");
    }
    @Override public void addCorsMappings(CorsRegistry r) {
        r.addMapping("/**")
         .allowedOriginPatterns("*")        // 生产改为前端域名
         .allowedMethods("*").allowedHeaders("*")
         .allowCredentials(true);
    }
}
```

### 5.2 api.js（fetch 封装）

```javascript
const API_BASE = 'http://localhost:8080/api'; // 改为你的云后端域名，如 https://lib.your-domain.com/api

async function request(path, options = {}) {
  const token = localStorage.getItem('token');
  const headers = { 'Content-Type': 'application/json' };
  if (token) headers['Authorization'] = 'Bearer ' + token;

  const res = await fetch(API_BASE + path, {
    ...options,
    headers,
    body: options.body ? JSON.stringify(options.body) : undefined
  });
  if (res.status === 401) { localStorage.clear(); location.href = 'login.html'; return; }
  const data = await res.json();
  if (data.code !== 200) { alert(data.message || '请求失败'); throw new Error(data.message); }
  return data.data;
}
// 便捷方法
const api = {
  get:  (p, q) => request(p + (q ? '?' + new URLSearchParams(q) : '')),
  post: (p, b) => request(p, { method: 'POST', body: b }),
  put:  (p, b) => request(p, { method: 'PUT', body: b }),
  del:  (p)    => request(p, { method: 'DELETE' })
};
```

### 5.3 auth.js

```javascript
const auth = {
  login(token, role) { localStorage.setItem('token', token); localStorage.setItem('role', role); },
  getToken()   { return localStorage.getItem('token'); },
  getRole()    { return localStorage.getItem('role'); },

  requireRole(role) {
```

### 5.4 页面与 fetch 调用对照

| 页面 | 调用接口 | 说明 |
|------|----------|------|
| user/login.html | `POST /api/user/register`、`POST /api/user/login` | 注册/登录后存 token，跳 books.html |
| user/books.html | `GET /api/books?keyword=`、`POST /api/borrow`、`POST /api/comments` | 搜索/借书/评论 |
| user/my.html | `GET /api/borrow/my`、`POST /api/borrow/{id}/return` | 我的借阅 + 还书 |
| admin/admin-login.html | `POST /api/admin/login` | 管理员登录，跳 admin-books.html |
| admin/admin-books.html | `GET /api/admin/books`(列表)、`POST/PUT/DELETE /api/admin/books[/id]` | 图书 CRUD |
| admin/admin-users.html | `GET /api/admin/users`、`PUT /api/admin/users/{id}/status` | 用户管理 |
| admin/admin-borrows.html | `GET /api/admin/borrows` | 所有借阅 |
| admin/admin-comments.html | `GET /api/admin/comments`、`DELETE /api/admin/comments/{id}` | 评论管理 |

> **前端不保存业务数据**：图书、借阅、评论等全部来自接口实时渲染；仅 `localStorage` 存 JWT（鉴权凭证）。双击 HTML 即可打开，但数据交互需后端运行且 CORS 放行。

### 5.5 样式约定（style.css）

轻量原生样式：卡片容器、表格、按钮（主色 `#3B82FF`、危险色 `#DC2626`）、表单输入框。不引入任何 CSS 框架。详细见 `frontend/assets/style.css`。

## 6. 云数据库与部署配置

### 6.1 申请云 MySQL

- 腾讯云/阿里云学生服务器（几十元/年）+ 云数据库 MySQL（独立实例，自动备份）。
- 控制台获取：主机地址（如 `cdb-xxxx.sql.tencentcdb.com`）、端口（3306）、库名（自建 `library`）、账号、密码。

### 6.2 初始化

- 本地用 Navicat / 命令行连接云库，执行第 2 章建表 SQL + 管理员初始化。
- 确认 `user`、`book`、`borrow`、`comment` 四张表创建成功。

### 6.3 后端连接（已在 4.7 给出）

- `application.yml` 的 `spring.datasource.url` 指向云地址。
- **切勿**把数据库放本机 MySQL 对外服务。

### 6.4 部署

1. 后端：`mvn package` 打 jar，`nohup java -jar app.jar &` 跑在云服务器。
2. 前端：`frontend/` 静态文件上传至云服务器 Nginx、或腾讯云 COS / 阿里云 OSS（配 CDN）。
3. 跨域：`WebConfig` 的 `allowedOriginPatterns` 改为前端真实域名。

### 6.5 2000 用户支撑要点

- MySQL 单机轻松支撑 2000 用户、数万条借阅记录。
- 已为 `title`、`category`、`user_id`、`book_id`、`status` 建索引，避免全表扫描。
- 连接池用默认 HikariCP（按需调大 `maximum-pool-size`）。
- 静态资源走 CDN，减轻后端压力。

## 7. 本地开发联调

1. 本地起一个 SpringBoot 工程（按第 4 章片段），`application.yml` 暂时指向本地 MySQL 调试。
2. 前端 `frontend/assets/api.js` 的 `API_BASE` 设为 `http://localhost:8080/api`。
3. 双击 `frontend/user/login.html` 即可注册/登录/借书；`frontend/admin/admin-login.html` 进入后台。
4. 功能联调通过后，把 `API_BASE` 改为云后端域名，数据库切到云 MySQL，部署上线。
